# presenting-symptoms-and-cancer-stage

# What is this for
The purpose of this repository is to share pre-processing and analysis code for the study:  
"Associations between presenting symptoms and stage at diagnosis of cancer: Evidence from the English National Cancer Diagnosis Audit" by  
Nadine Zakkak, Matthew Barclay, Ruth Swann, Sean McPhail, Greg Rubin, Gary A. Abel, Georgios Lyratzopoulos

Published results can be shared upon request.
